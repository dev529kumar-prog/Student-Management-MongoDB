
# Student Management System using MongoDB

## Project Overview
This project is based on a Student Management System using MongoDB. It demonstrates how NoSQL databases can be used to store, manage, and retrieve student information.

## Objectives
- To understand MongoDB database operations.
- To create and manage student collections.
- To insert, update, delete and retrieve student records.
- To perform queries using comparison and logical operators.

## Technologies Used
- MongoDB
- MongoDB Query Language (MQL)
- GitHub

## Operations Covered
- Create Database and Collection
- Insert Documents
- Find Documents
- Update Documents
- Delete Documents
- Comparison Operators
- Logical Operators
- Sorting and Limiting
- Count Documents

## Dataset
The project uses student records containing details such as roll number, name, age, marks and city.
